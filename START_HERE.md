## 🔧 Customization Made Easy

### Change Primary Color
```css
--primary-blue: #YOUR_COLOR;  /* in index.css line 7 */
```

### Adjust Blur Amount
```css
backdrop-filter: blur(25px);  /* Change value */
```

### Add Navigation Item
```jsx
{ 
  id: 'new-view', 
  label: 'New View', 
  hint: 'Description',
  icon: '🎯'
}
```

### Use CSS Variables
```css
.my-component {
  color: var(--primary-blue);
  padding: var(--spacing-lg);
  font-family: var(--font-display);
  border-radius: var(--radius-xl);
}
```
